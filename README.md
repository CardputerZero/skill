# CardputerZero Skills

Codex skills for Cardputer Zero app development, APPLaunch packaging, and VibAPP generation workflows.

## Included Skills

- `cardputer-zero-application` - build, port, package, review, and validate Cardputer Zero applications that run through APPLaunch or are generated by VibAPP.
- `cardputer-app-publish` - guide users through publishing CardputerZero apps to the AppStore using czdev CLI (login, build, bump, publish, PR review, release lifecycle).
